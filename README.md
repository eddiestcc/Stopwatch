# EyeWatch

A simple stopwatch web application built with HTML, CSS, and vanilla JavaScript. Developed to practice DOM manipulation, event handling, and implementing functional buttons.

## Features
- **Start:** Begins the stopwatch.
- **Stop:** Pauses the stopwatch.
- **Reset:** Resets the timer to zero.

## Built With
- HTML5
- CSS3
- Vanilla JavaScript

## Concepts Practiced
- DOM manipulation
- JavaScript event listeners
- Button functionality
- Timer logic using JavaScript

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/eddiestcc/Stopwatch.git
   ```
2. Open `index.html` in your browser.

No additional dependencies required.
